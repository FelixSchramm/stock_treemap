# modell-analyse

Pro App ein Unterordner, darin pro gefundenem Modell eine Datei: `modell-analyse/<app-name>/<modell-name>.md`.

Neue Analyse anlegen: `mkdir -p modell-analyse/<app-name> && cp modell-analyse/_vorlage/modell-name.md modell-analyse/<app-name>/<modell-name>.md`

Die Modelldateien selbst bleiben unter `workspace/` und werden nicht committet. Hintergrund zu den Formaten: `notes/formate.md`.
