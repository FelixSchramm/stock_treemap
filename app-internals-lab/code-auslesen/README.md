# code-auslesen

Pro untersuchter App ein Unterordner `code-auslesen/<app-name>/` mit:

- `README.md`: Was ist die App technisch (React Native, Flutter, nativ Android/iOS, ...), und wie wurde der Code extrahiert?
- `findings.md`: Interessante Fundstellen mit kurzem Code-Ausschnitt, eigener Erklärung und Einordnung in den App-Kontext.

Neue App anlegen: `cp -r code-auslesen/_vorlage code-auslesen/<app-name>`
