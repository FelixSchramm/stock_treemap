# weitere-analysen

Alles, was über reinen Code und Modelle hinausgeht:

- `netzwerk-traffic/<app-name>.md`: Endpunkte und Remote-Configs, die die App beim Start oder bei bestimmten Aktionen abruft (nur eigener Traffic).
- `permissions-sdks/<app-name>.md`: Berechtigungen und verbaute Drittanbieter-SDKs (Tracking, Analytics, Ads, Crash-Reporting).
- `storage/<app-name>.md`: Was lokal auf dem Gerät gespeichert wird (SharedPreferences, SQLite, Caches, Dateien).

Jeder Unterordner enthält eine `_vorlage.md`. Rohmitschnitte (HAR, PCAP) und Datenbank-Abzüge werden nicht committet.
