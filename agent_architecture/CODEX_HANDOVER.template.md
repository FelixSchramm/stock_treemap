# Codex task handoff

Post a filled copy as a comment on the GitHub issue or pull request. This is a compact message between separate, isolated Codex Cloud tasks; it is not a persistent file automatically read by Codex.

- **Issue:** #<number> — <stable ID and title>
- **Role and status:** Worker / Reviewer — complete / blocked / changes requested
- **Branch and PR:** <branch> / <full PR URL>
- **Commit reviewed or produced:** <full SHA>
- **Work completed or review scope:** <brief, factual summary>
- **Checks:** <commands and pass/fail results>
- **Findings or unresolved questions:** <severity and concrete evidence, or none>
- **Next action:** <owner starts reviewer / worker addresses findings / owner reviews and merges / owner supplies input>

Do not include secrets, real holdings, sheet URLs, personal account details, or unredacted provider output.
